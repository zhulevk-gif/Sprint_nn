# Итоговый проект: API-тесты сервиса «Доска»

Проект содержит автотесты для учебного сервиса «Доска». В проекте реализованы проверки регистрации пользователя, авторизации, создания объявления, редактирования объявления и удаления объявления.

## Структура проекта

```text
Sprint_nn/
├── api_client.py
├── data.py
├── generators.py
├── utils.py
├── pytest.ini
├── requirements.txt
├── README.md
└── test/
    ├── conftest.py
    ├── test_registration.py
    ├── test_login.py
    ├── test_create_advertisement.py
    ├── test_update_advertisement.py
    └── test_delete_advertisement.py
```

## Покрытые сценарии

- Успешная регистрация нового пользователя с уникальным email.
- Повторная регистрация пользователя с уже существующим email.
- Успешная авторизация зарегистрированного пользователя.
- Успешное создание объявления.
- Успешное редактирование объявления.
- Попытка редактирования чужого объявления под другим токеном.
- Успешное удаление объявления.

## Используемые технологии

- Python
- pytest
- requests
- requests-toolbelt

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v
```

## Особенности реализации

- Для предусловий используются фикстуры из `conftest.py`.
- Тестовые данные вынесены в `data.py`.
- Генерация уникального email вынесена в `generators.py`.
- Логика работы с API вынесена в `api_client.py`.
- Вспомогательные методы для обработки ответов вынесены в `utils.py`.
- Для запросов с `multipart/form-data` используется `MultipartEncoder`.
- В проекте используется параметр `verify=False` для отправки запросов к тестовому сервису.

## Результат

По итоговому прогону успешно выполняются 7 тестов:

- 2 теста на регистрацию
- 1 тест на авторизацию
- 1 тест на создание объявления
- 2 теста на редактирование объявления
- 1 тест на удаление объявления
